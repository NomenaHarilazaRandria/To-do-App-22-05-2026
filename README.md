# Advanced To-Do List

A modern and interactive To-Do List application built with HTML, CSS, and Vanilla JavaScript.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Save tasks with localStorage
- Automatically reload saved tasks
- Filter tasks:
  - All
  - In Progress
  - Completed
- Responsive task layout
- Support for long task text
- Clean UI with shadows and hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- localStorage API
